## User-visible behavior and review fixes

- Cron triggers now recur for every scheduled boundary. Native dqlite listeners check leadership at each fire/catchup; followers do not admit the tick. PostgreSQL has no dqlite election. This leader gate does not claim atomic deduplication across a leadership transition within one tick.
- Server shutdown cancels in-process ownership with a distinct shutdown cause and leaves durable runs/task claims available for recovery. User cancellation and run deadlines retain their terminal behavior. Local-mode restart recovery remains a separate qualification limit.
- Deterministic incident rules refuse approval-tier actions (`SkipTask`, `OverrideSchemaGate`, `ApplyJobdefPatch`); those actions need the approval path rather than bypassing it through a rule.
- Connector `_caesium_actor` reservation applies to the action envelope root. Nested schema properties and nested `const`/`enum` data may use the name; the previous document-wide rejection was broader. Root `additionalProperties: false` and caller-payload validation precede server actor stamping. See [connector schema policy](../../connectors.md).
- Statistics query errors return a wrapped, redacted HTTP 500 rather than a partial success. Transient failures can make the console's summary poll unavailable; no partial-result API is introduced in this maintenance change.
- Commands declaring `cobra.NoArgs` reject formerly ignored stray positional arguments. Incomplete 2xx reads exit nonzero and identify the successful HTTP status plus possible applied mutation; callers should verify state before retrying.
- End-to-end load p50/p99 retain the original index formula used to calibrate budgets. The generic nearest-rank helper is not substituted for those existing comparisons.
- Required maintenance collectors fail on missing image/config prerequisites. Hermetic tagged helper regressions run in both architecture unit lanes with exact named PASS requirements; capability skips in other optional lanes do not qualify these journeys.
