Source: [googlefonts/sometype-mono](https://github.com/googlefonts/sometype-mono/tree/cf583c22bc6279d23e587e3ca310e131dd277286), commit `cf583c22bc6279d23e587e3ca310e131dd277286`, `fonts/webfonts/`. The upstream repository has no published GitHub release; these are its supplied WOFF2 webfonts.
